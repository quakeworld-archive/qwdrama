Sunday 29th July, 2007 | Skip to comments (2)

Hold on to your horses!

Goldrush has been offline for a while due to updates and also the fact that there hasn’t been so much official games played during the summer.

However there has been some minor and major updates to both the functionality and rules.


Goldrush 1.0 features/changelist:

  • Live countdown to game expiration
  • Only 1 bet allowed per game per user
  • Graphical statistics on games
  • Automated balance update (every Sunday broke user gets $50)
  • Comments on games
  • Auto-login
  • Bonus system: Get $100 for winning FOTW!

I know that I promised some other features like “bet modes” for each game but I really don’t have the time atm I don’t want to have the site offline anymore since there actually are some official games beeing play nowadays.

For those that has forgot their passwords, go recover it or register for some heavy betting action!
