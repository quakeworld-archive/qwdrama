Use the force, Open source

Thursday 26th April, 2007 | Skip to comments (10)

Not using Linux as your main operating system.. duh? If you want to play most of the modern games its probably not for you. And guess what, Quake runs just fine on it. Other than that I don’t see why you should NOT use it. So hereby I invite the quake community to fetch the freshly released Ubuntu which should work better than ever.

Ever heard about Compiz or Beryl? It’s installed by default if the hardware supports it, and its also included in the livecd which also has the installer built into it.

Why not use Windows, like everybody else? Well if you have some spare time and want to learn something new, try it! It’s free both as in beer and in speech. Get it while it’s hot.

  • Take the tour
  • Go straight to the iso’s

This is Beryl showing of just 2 plugins, cube and 3d effect.

Ran into some problems? Don’t know how things work? I’d be happy to help out with anything. Also #linux.qw is a somewhat unofficial place for support but i think the guys there can handle it ;)
