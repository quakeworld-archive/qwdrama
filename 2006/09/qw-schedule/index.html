QW Schedule

Friday 22nd September, 2006 | Skip to comments (0)

It has been a long time since there were any activity here at qwdrama, maybe too long. Anyway we want you to know that we are not dead, this has just been a summerbreak as for anyone else in the QW scene.

We have been working on some projects and are happy to announce a new qwdrama subsite:

QW Schedule (schedule.qwdrama.com)

This is a schedule for upcoming games and QW events. It’s very easy to view, add and edit events. This idea was brought to light by Reppie who suggested it in the “Suggestionbox” and got the highest rating among the voters.

So next time you set a date and time for a game don’t forget entering it to the qw schedule!
